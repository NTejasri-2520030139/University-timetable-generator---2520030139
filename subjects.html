AC-3 Constraint Propagation

Arc Consistency Algorithm reduces the search space by eliminating impossible value assignments before and during the search phase.

MRV Heuristic

Minimum Remaining Values selects the most constrained variable first, dramatically reducing backtracking and solving time.

📊

Degree Heuristic

Breaks MRV ties by choosing the variable involved in the most constraints, further reducing the effective search space.

⚖️

LCV — Least Constraining Value

Orders domain values to try the least constraining option first, leaving maximum flexibility for subsequent variable assignments.

This application implements every topic covered in CO3 — Constraint Satisfaction Problems. The timetable scheduling problem is modeled as a CSP where each class session is a variable, valid (teacher, room, timeslot) combinations form the domain, and clash-prevention rules define the constraints.
